AI Model Explanation (SHAP)

What are SHAP values?
SHAP (SHapley Additive exPlanations) values show how much each codon influences the AI model's prediction.

✓ Positive values (Green): This codon increases the model's confidence that it should be used for this amino acid.

✗ Negative values (Red): This codon decreases the model's confidence. The model suggests avoiding this codon for optimal expression.

Value magnitude: The size of the value indicates strength of influence.
